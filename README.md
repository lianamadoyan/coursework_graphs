# coursework_graphs
Coursework: Detection of structural patterns in network systems.
Structural analysis of real networks (degree distribution, clustering, shortest paths,
centralities) and comparison with the Erdős–Rényi random graph model, using Python and NetworkX.

## Data sources

- **Airline network.** [OpenFlights](https://openflights.org/data.html) route database
  (`data/routes.dat`), released under the Open Database License (ODbL).
  Source: https://github.com/jpatokal/openflights/tree/master/data
- **Internet AS topology.** [SNAP as-733](https://snap.stanford.edu/data/as-733.html)
  (Stanford Network Analysis Project), snapshot of January 2, 2000.
- **C. elegans neural network.** [Netzschleuder, celegans_2019](https://networks.skewed.de/net/celegans_2019)
